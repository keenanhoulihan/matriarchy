# sara-houlihan.com

Static site for Sara A. Houlihan's #TheMatriarchyIsStrong series (Beverly Art Walk). Served by GitHub Pages from `main`; `CNAME` points to sara-houlihan.com. No build step.

- `index.html`: page markup (nav, two tabs, hero slideshow, works, about the artist)
- `css/style.css`: all styles; palette lives in the `:root` variables
- `js/main.js`: tab switching and scroll reveal
- `images/hero/`: crossfade slideshow images (hero-01 to hero-09, 5s apart)
- `images/works/`: one file per artwork, named after the piece
- `images/sara-portrait.jpg`: About the Artist photo

Pushing to `main` updates the live site.
